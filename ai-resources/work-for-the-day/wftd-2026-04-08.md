# Work for the Day — 2026-04-08
# Flujo: Advanced Deck Library

## Contexto y objetivo

La página `decks-library` tiene dos modos de visualización de mazos:

| Modo | Descripción |
|---|---|
| **Simple (Grid)** | Lista plana de todos los mazos guardados tal y como fueron creados |
| **Advanced Decklist** | Vista agrupada por **arquetipos/tipologías** de mazo. Al pulsar una tipología se abre un modal con todas las versiones de ese arquetipo |

El cambio entre modos se gestiona con un toggle. Actualmente el toggle es un `<input type="checkbox">` hardcodeado directamente en el HTML de la página, sin animación real, sin encapsulación y sin reutilización.

---

## Diagnóstico del estado actual

### Toggle (problema principal)
- El toggle vive en `decks-library.component.html` como HTML crudo con CSS propio en `decks-library.component.scss`.
- No existe como componente atom reutilizable.
- Tiene transición CSS básica pero la animación del slider no está bien construida (el knob se mueve pero no hay easing ni estado activo visual potente).
- No tiene `@Input`, `@Output` ni `label` configurables.
- No sigue el patrón del resto de atoms del proyecto (ver `theme-toggle`, `button`, `badge`…).

### Vista Advanced Decklist (sin implementar)
- Actualmente es un placeholder `<div>` con un `<h2>` y un `<p>`.
- No existe lógica de agrupación por arquetipo.
- No existe componente de "tipología card".
- No existe modal para versiones de un arquetipo.

### ✅ PASO 1 — Crear el atom `ToggleSwitchComponent`
**Prioridad: Alta — bloqueante para todo lo demás** | **COMPLETADO 2026-04-08**

Crear un componente atom genérico, animado y accesible:

```
src/app/shared/components/atoms/toggle-switch/
  toggle-switch.component.ts
  toggle-switch.component.html
  toggle-switch.component.scss
```

**Especificaciones del componente:**

```typescript
// Inputs
@Input() checked: boolean = false;        // Estado actual
@Input() label: string = '';              // Label visible al lado del toggle
@Input() labelPosition: 'left' | 'right' = 'right';
@Input() size: 'small' | 'medium' | 'large' = 'medium';
@Input() disabled: boolean = false;
@Input() ariaLabel?: string;              // Accesibilidad

// Output
@Output() toggled = new EventEmitter<boolean>();
```

**Animación requerida:**
- El knob se desplaza con `transition: transform 0.25s cubic-bezier(0.4, 0, 0.2, 1)`.
- El track cambia de color con `transition: background-color 0.25s ease`.
- En estado `checked` el track toma color `var(--theme-color-primary)`.
- En estado `unchecked` el track toma `var(--theme-color-bg-elevated)` con borde sutil.
- El knob tiene sombra `box-shadow` para dar profundidad.
- El label tiene transición de color suave sincronizada con el estado.

**Accesibilidad:**
- Usar `role="switch"` + `aria-checked` en el elemento raíz o usar `<input type="checkbox">` nativo pero oculto con estilos CSS (patrón recomendado para screen readers).
- `tabindex` controlado. Focus visible con outline usando `var(--theme-color-primary)`.

**Registro:**
- Añadir a `COMPONENTS` en `shared.module.ts`.
- Exportar en `shared.module.ts`.
